# FUTURE_DS_01
📊 Ecommerce Sales Dashboard

This project is an Ecommerce Sales Dashboard built to analyze and visualize sales performance across different dimensions such as state, category, customer, and payment modes. The dashboard provides actionable insights into sales trends, profit distribution, and customer behavior.

🚀 Features

Key Metrics Overview:

Total Sales Amount (438K)

Total Quantity Sold (5615)

Total Profit (37K)

Average Order Value (AOV) (121K)

State-wise Sales Analysis: Visual breakdown of sales performance by states such as Maharashtra, Madhya Pradesh, Uttar Pradesh, etc.

Category & Sub-Category Insights:

Quantity sold by categories (Clothing, Electronics, Furniture).

Profit contribution by sub-categories (Printers, Bookcases, Sarees, Accessories, Tables, etc.).

Customer-Level Sales: Top customers contributing to revenue (Hariyanth, Madhav, Madan Mohan, etc.).

Payment Mode Distribution: Analysis of sales done through COD, UPI, Debit Card, Credit Card, and EMI.

Monthly Profit Trends: Profit and loss trends across months, highlighting seasonal patterns.

Filters: Quarterly and yearly filters for dynamic analysis.

Visualization: Interactive charts, graphs, and filters

🎯 Purpose

The dashboard helps ecommerce businesses to:

Monitor sales and profit trends in real-time.

Identify top-performing categories, customers, and states.

Optimize business decisions using data-driven insights.
